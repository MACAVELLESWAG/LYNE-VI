# LYNE VI

A photorealistic JUCE audio plugin powered by Neural Amp Modeler. Parody of the legendary Line 6 POD (the red bean!).

## Features
- Neural network amp/cab modeling
- Stunning bean-shaped GUI with filmstrip knobs
- VST3 / AU / Standalone

## Building
1. Clone repo
2. git submodule update --init --recursive
3. cmake -B build
4. cmake --build build --config Release

Built with ❤️ using JUCE + NAM
